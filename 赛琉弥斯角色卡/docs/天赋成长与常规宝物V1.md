# 天赋成长与常规宝物 V1

用户已授权加入天赋、按初始境界加权抽取，并由实现者确定天赋等级、效果与数值；已授权人物成长、装备生效、数值上限和修为秘宝结算。下列为本版确定的配置。宝物获取门槛、投放、概率与频率继续留在 INT-14，不实现投放或自动发放。免死、不死等特殊机制仍须先确认[专项方案](特殊物品与AI接入方案.md)。

## 天赋

天赋只影响修为积累，不直接加生命、攻防、能量、技能威力或恢复速度。它不保证人物必达某阶，也不自动给予技能。

| --- | ---: | ---: |
| 平常 | 1 | 360 |
| 良好 | 1.5 | 240 |
| 优秀 | 2 | 180 |
| 卓越 | 3 | 120 |
| 天才 | 4.5 | 80 |
| 绝世 | 6 | 60 |

人物首次有完整面板时抽取一次，保存等级、首次建档境界和规则版本。初始境界取已有路线最高阶；只用于首次抽取，不随以后晋阶提高概率或重抽。已经有天赋的存档保留原结果。对旧存档首次接入时，以当前已知面板境界作抽取依据，不杜撰无法核实的历史初始境界。

## 后台成长

本阶无宝物速度为 `100×R÷360×天赋倍率` 修为／剧情日。晋阶门槛保持 `100RQ`，Q＝2^(R−1)。因此普通天赋各阶分别需 1、2、4、8、16、32、64 个星辉年，R1 到 R8 合计 127 年；绝世为约 21.17 年。此表从各阶零进度计算，不计秘宝。

时间来自当前聊天有效分支的权威剧情时钟，支持星辉历与独立玩法“第N日”。按已结算时点补算差额，不要求安排训练，离场不停。首次接入从当时开始，不补发未知历史；无法识别时间时暂停。历法切换重新锚定时间，不把“第1日”到星辉历的差异当作数百年修炼。

后台每 30 秒检查已提交的剧情时间，生成前、回复结束、分支切换与装备操作也同步结算；现实经过 30 秒本身不提供修为。数据没有变化时不写存档，正文生成过程中暂停定时写入。

结算按晋阶边界分段，一次长期跳时最多循环七次，不逐日循环。升阶扣门槛、保留溢出，并按新阶速度结算剩余时间。R8 不新增境界，也不继续积累无用途的大数。

已有 N2 单路线面板按本来 Q 倍率推进，保留体型与原面板系数。晋阶后生命和能量按旧当前值／旧有效上限比例映射一次并向下取整，不自动回满，零余额仍为零。兼修面板合成和非 N2 模板尚未定义：仍保留天赋与修为，晋阶暂缓，界面明确提示，不擅自拼接模板。

## 常规宝物生效

品阶 J＝1…8，Qj＝2^(J−1)。对应路线达到宝物品阶才激活增幅；法杖强制法力路线，骑士可以佩戴但不产生任何增幅。普通道具只有拥有关系不生效，佩戴才激活。一次写入先按旧装备结算成长，再修改装备并重算面板。

每件宝物只有一份词条总预算：一条完整效果或两条半效果。数值由类型、品阶和份额确定，不能给每条都领取一份满额预算。本版只开放以下可直接结算的效果，不把任意文字解释成新能力。

| 一份完整效果 | 数值 |
| --- | --- |
| 固定生命上限 | +20Qj² |
| 固定路线能量上限 | +20Qj |
| 固定普通攻击 | +Qj² |
| 固定防御 | +0.5Qj² |
| 单属性百分比 | p＝min(5%×J,20%)；增益上限为同品阶对应固定效果的 1.5 倍 |
| 佩戴型成长加速 | p 同上；额外修为／日上限为该品阶平常天赋速度×p×1.5 |
| 消耗型修为 | 向指定已有路线增加 10JQj 修为 |

属性百分比只按无宝物的基础 B 计算，单条为 `min(B×p,K)`；两条半效果同时按一半百分比与一半 K。百分比起点通常低于固定效果，但封顶略高，避免固定词条始终更优。

每项属性的所有固定及百分比增益相加，再限为基础 B 的 50%。每条宝物的 K 来自自身品阶，人物变强不提高 K。零基础的百分比增益仍为零；固定增益只在已有 N2 单路线参考值明确时使用该参考值的 50% 作为额度。

无宝物基础面板独立保存，界面与 AI 读取的是合成后的有效面板。反复穿脱不能把上一次有效值变成新基础。穿戴不增加当前生命或能量，卸下时仅压到新上限；C 始终为有效能量上限的 20%。通常防护已包含在 N2 基础，不重复叠加军甲。

成长加速同样逐条按固定修为／日封顶，总额外速度最多为天赋速度的 50%。它只作用于指定已有路线，不回溯生效。旧版仅含固定攻防的记录可继续读取，仍受人物总上限限制，不自动伪造新词条。

消耗型修为秘宝每个剧情日、每条路线最多吸收首次使用前本阶门槛的 20%。该日第一次成功使用时锁定额度，晋阶、更换秘宝、重新打开界面均不刷新。无法完整吸收时保留整件；成功时扣数量、加修为、晋阶与日额度一起保存。R8、未明确的晋阶模板、路线不符、时间不明或时间早于存档均不消耗。

对系增伤和通用伤害仍要接入实际目标、动作与命中事件，当前不激活未接好的战斗触发词条，避免先写正文再改出矛盾结果。特殊物品没有随本版开放执行处理器。

## AI 与界面

现有 `玩法正文` 视图提供天赋等级、成长倍率、当前有效面板、武器名称和待描写晋升事实。隐藏基础面板、时间游标、抽签依据、吸收账和完整宝物词条，AI 不执行算式。晋升提示只说明已发生结果，由 AI 决定是否出场；成功的 MVU 回复后清除其前态已提供的提示，本轮新晋升另行排入。

没有注册通用剧情信息汇总器，也没有新增模型请求或聊天楼层。若以后采用通用汇总器承载这些事实，须由用户选择，并移除重复来源。

人物界面仍使用既有两列“天赋”行和成长说明行，显示等级／倍率与每日修为。没有新增卡片、改图片、扩大装备栏或重排网格；独立演示未抽取真实人物天赋，显示“待抽取”。

## 交付与平衡边界

本版更新源码、schema、变量列表／更新规则、成长条目和独立脚本包；不等于已经安装到用户当前酒馆。既有聊天必须替换唯一变量结构脚本和配套条目，不用空初始化覆盖存档。

检查覆盖概率分布的单调性、固定抽签、跨时段与重复结算、晋阶余额比例、品阶绝对上限、穿脱、秘宝事务、日额度、AI 视图以及聊天／分支隔离。没有调用剧情 AI 或运行全仓测试。宝物获得成本与频率尚未确定，因此只保证这些已检查的数值边界，不宣称完整成长和经济节奏已获得实测保证。

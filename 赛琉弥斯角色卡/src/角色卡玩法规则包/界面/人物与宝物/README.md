# 人物与宝物界面

[视觉约定](DESIGN.md) · [产品边界](PRODUCT.md)

宝物藏室与领地人物两页采用羊皮纸蓝银界面。所有物件按五个大类使用统一图标：武器、防具、饰品、修为秘宝、特殊物品；法杖也使用武器类图标。右侧详情不重复展示图片。

![宝物藏室](preview/treasures.webp) ![领地人物](preview/people.webp)

## 查看与构建

从仓库根目录运行：

```powershell
node '赛琉弥斯角色卡/tools/build-treasure-ui.mjs'
node '赛琉弥斯角色卡/tools/serve-treasure-ui.mjs'
```

打开 http://127.0.0.1:8356/#treasures 或 #people。本地服务不对外网监听。独立打开时为演示模式，示例宝物不写入聊天，底部可重置、查看容量提醒和空藏室。

发布目录为根 `dist/角色卡玩法规则包/界面/人物与宝物/`，需保留 app.js、style.css 与 assets。图片独立引用，无 SVG、无内嵌图片。

## 装备变量接入

同源酒馆前端检测到更新后的“变量结构”角色脚本后，读取当前聊天、当前有效 swipe 的玩法数据，关闭示例数据与重置工具。跨源独立预览保持演示模式。

- 人物装备引用同一库存中的物件，不复制数量。支持佩戴、替换、拆堆、卸下和静默丢弃；删除最后一件同时解除装备引用。
- 写入前验证聊天、分支及存档版本；旧界面操作被拒绝并刷新，不把旧选择写入新聊天。共享宿主上只有操作函数，没有跨聊天的存档缓存。
- 法杖明确登记为法力路线武器，骑士可佩戴，路线不符时增幅为零。路线判定函数供各效果处理器复用，不以名称猜测武器路线。
- AI 从只读“玩法正文”视图读取人物的当前武器名称；隐藏装备引用、脚本宝物库存与效果配置。普通剧情变量继续按原 /玩法/... 路径更新。
- AI 更新不能创建脚本宝物或修改装备；脚本生成与获取机制尚未启用。初始人物与库存不凭空增加示例装备。

变量结构脚本可用 `node 赛琉弥斯角色卡/tools/build-gameplay-variable-script.mjs` 独立构建。需要同时替换变量结构脚本与“变量列表”“变量更新规则”世界书条目。构建好的注册脚本为 `dist/角色卡玩法规则包/脚本/变量结构/index.js`，配套世界书在 `dist/角色卡玩法规则包/脚本/变量结构/角色卡玩法_MVU变量.worldbook.json`。仅替换项目对应条目，不覆盖其他世界观条目；既有聊天不得重跑空初始化。当前交付没有直接安装到用户酒馆。

通用剧情信息汇总器仍未注册武器事实；已有 MVU 精简视图负责武器名称读取。注册汇总器须另获用户确认。

## 当前边界

数值效果库、基础与最终面板合成、消耗型秘宝结算、自动成长、容量阈值及宝物投放尚待后续确定。真实存档模式暂不开放消耗操作，避免扣掉物品却没有效果。六个装备位置沿用现有界面映射，不代表最终槽位规则已定。

武器路线限制与固定加成筛选已实现，但尚未把完整宝物效果接入战斗结算；佩戴不擅改原人物攻防。

## 人物图片

默认使用已确认的女性人物徽记羊皮纸底图，仅作通用占位，不代表人物外观。独立预览可上传不超过 8 MB 的 PNG/JPG/WebP，保存为本地 HTTP 图片地址；也可填写已有本地地址。映射文件位于项目 output 下的预览 portraits 目录，不发布用户图片。

预览图片映射不是聊天存档，正式酒馆的图片上传与分支映射待接入，不能把此全局预览表作为真实人物数据。

## 资源与核对

42 张运行时图片采用 WebP 质量 95，合计 2,075,478 字节。新增五张大类图使用已确认武器 v9 的淡灰扁平剪影风格，无棕色描边；移除了九张不再使用的单件插画。外框、纸面、按钮等仍取自已选概念图。尺寸、编码参数见 assets/webp-manifest.json，来源见 assets/sources.json。

原始 PNG 仅在本地保留；正常构建不需要重新生图或压缩。若修改工作图，可运行 tools/compress-treasure-ui-assets.mjs。图片编码使用独立临时 Chrome 配置，不连接用户浏览器。

校验只覆盖本次装备逻辑、旧变量兼容、局部编译及桌面/窄屏显示，不调用剧情 AI，不运行全仓测试。未确认的获取门槛、投放方式、频率和条件继续保留在 INT-14 待办。
